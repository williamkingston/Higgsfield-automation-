# Create a Full Fashion Campaign From One Photo

## What You'll Learn

You don't need a model, stylist, location, or weeks of planning to create a fashion campaign. With one image and a single prompt, you can generate a complete campaign while keeping the styling, mood, product, and visual direction consistent.

You can also change the creative direction and create completely different campaign concepts without reshooting anything.

This follows the same reference-image workflow used elsewhere in this repo's guides: upload your original image, describe the desired visual direction, and preserve the important product details.

## Tools You'll Need

- **Google Flow** — use it to create and develop the campaign visuals from your reference image.
- **Google Gemini** — use it to work with your reference image and generate the campaign concept.

## Step 1: Choose Your Reference Image

Start with a clear photo of the clothing or fashion look you want to build the campaign around.

For the best results:

- Use a high-resolution image
- Make sure the clothing is clearly visible
- Avoid heavy filters
- Keep important details unobstructed

The reference image should give the AI enough information to understand the garment, styling, and overall look.

## Step 2: Upload Your Image

Open Google Flow or Google Gemini and upload your image. Then use the image as the visual reference for the campaign.

## Step 3: Paste the Campaign Prompt

```
Using the uploaded image as the primary reference, create a complete high-end fashion campaign around the clothing shown.

Preserve the exact identity and important details of the clothing, including:
- Silhouette
- Fabric
- Colors
- Patterns
- Textures
- Logos
- Accessories

Build a cohesive fashion campaign with a premium editorial aesthetic.
Match the creative direction, styling, mood, lighting, composition, and environment to the clothing.

Create sophisticated fashion photography with professional model posing, refined styling, cinematic lighting, realistic materials, natural fabric texture, and high-end magazine-quality composition.

Keep the clothing consistent across every image.
The campaign should feel like it was created by a professional fashion photography team for a premium fashion brand.
```

The goal is to treat your original image as the reference while allowing AI to build the surrounding campaign concept.

## Step 4: Create Different Creative Directions

You don't have to stick with the first concept. Ask the AI to adapt the same campaign into different styles.

### Luxury Editorial

```
Reimagine this campaign as a luxury fashion editorial.
Use sophisticated architecture, dramatic natural lighting, refined model poses, cinematic composition, and high-end magazine photography.
Keep the clothing exactly consistent with the reference.
```

### Streetwear Campaign

```
Turn this into a premium streetwear campaign.
Use an urban environment, dynamic compositions, contemporary styling, bold framing, and cinematic lighting.
Keep the clothing, colors, logos, and details consistent.
```

### Minimal Studio Campaign

```
Create a minimalist studio fashion campaign.
Use a clean background, controlled studio lighting, elegant posing, subtle shadows, and a sophisticated editorial composition.
Keep the clothing identical to the reference image.
```

## Step 5: Expand It Into a Full Campaign

Once you have a direction you like, ask AI to create multiple campaign assets:

```
Expand this concept into a complete fashion campaign.

Create:
1. Hero campaign image
2. Full-body editorial shot
3. Close-up fashion detail
4. Lifestyle image
5. Social media campaign image
6. Website banner
7. Magazine-style cover

Maintain the same clothing, styling, visual identity, lighting language, and overall creative direction across the entire campaign.
```

Now one original image can become an entire set of campaign visuals.
